## 撮影リスト（実機）

スマホで 撮れます。**横向き**・**明るすぎない 部屋**（LED が 白飛びしない）で。

| ID | 内容 | 長さ | ポイント |
|---|---|---|---|
| R1 | ボードの 開封・全体 | 5秒 | 手のひらに のせて 小ささが わかるように |
| R2 | ボードの アップ（USB 左、文字が 読める 向き） | 5秒 | S1・S2・LED の 位置が わかるように |
| R3 | USB を さす | 3秒 | |
| R4 | `2_write_sram.bat` を ダブルクリック → 「おわり！」 | 10秒 | 画面録画（Win+G や OBS） |
| R5 | なにも おさない（右はしが 点滅） | 4秒 | 三脚 or 置き撮り |
| R6 | S1 を おす（右 → 左） | 5秒 | つまようじ等で おすと 指で 隠れない |
| R7 | S2 を おす（外 → 内） | 5秒 | |
| R8 | S1 と S2 を いっしょに（交互に点滅） | 5秒 | |
| R9 | USB を ぬいて さしなおす → そのまま 動く（Flash） | 8秒 | ③ の「ずっと」の 説明用 |
| R10 | ブレッドボードに さした ようす（引き） | 5秒 | エンディングの 前に |

> いまある 実機動画（S2 / S1+S2）は R7・R8 に そのまま 使えます。
> S1 の 動画は LED の 向きを 直す 前の もの なので、**R6 は 撮り直し** が おすすめです。
