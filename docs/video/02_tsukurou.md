## ナレーション原稿（通し）

> この 光ってる ボードの 中に、ぼくらが 作った CPU が 入ってる。名前は TTA-8。
>
> ふつうの CPU には 命令が 何百 種類も ある。でも TTA-8 の 命令は…… たった 2つ！
> READ、よむ。そして WRITE、かく。
> 部品から 数を 受け取るのが READ、部品に 数を わたすのが WRITE。
>
> 数を 運ぶのは、V という はこびや。
> 3 を A に、5 を B に わたして、ALU_ADD を READ すると……答えの 8 が、もう できてる！
> 計算するのは 部品の ほう。V は 運ぶだけ！
>
> じゃあ ジャンプは？ これも 書くだけ。JMP に 番地を 書くと、そこへ ジャンプ。
> JZ に 書くと、A が 0 の ときだけ ジャンプする。
> たす、ひく、0 なら ジャンプ。数を覚えて繰り返せば、
> かけ算やわり算も作れるんだ。
>
> そして これが、TTA-8 の 設計図。Verilog という ことばで 書いてある。CPU ぜんぶで…… 53行！
> この 設計図を、FPGA という 回路を 書きかえられる チップに 書きこむと、本物の CPU に 変身する。
>
> ブラウザの TTA-8 ラボなら、ボードが なくても CPU の 中を 1命令ずつ 見られる。V が 走る ようすを 見てみて！
>
> ブレッドボードが あれば、このボードの 外がわに 色々な 回路を 付けられる。
> おれたちの ぼうけん（電子工作）は、これからだ！
