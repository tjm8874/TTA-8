## ナレーション原稿（通し）

> 用意するのは、Tang Nano 20K という FPGA ボードと、USB ケーブル。
> ケーブルは データ通信できる ものを 使ってね。充電専用だと、パソコンが ボードを 見つけられないんだ。
> 「TANG NANO 20K」の 文字が 読める 向きに 置こう。左上が S2、左下が S1、下に LED が 6こ。
>
> GitHub から プロジェクトを ダウンロード。FPGA_Tool フォルダに、書きこむ 道具が ぜんぶ 入ってる。
> Windows なら、はじめに 1回だけ 0_setup_driver。
> Zadig で USB Debugger の Interface 0 を えらんで、Replace Driver！
> 1_check_board で「GW2A」と 出たら、ボードと つながった しるし。
>
> いよいよ 2_write_sram を ダブルクリック……「おわり！」
> なにも おさないと、右はしが 点滅。S1 で 右から 左へ。S2 で 外から 内へ。両方 おすと、交互に 点滅！
> 3_write_flash で 書きこめば、電源を 切っても 消えない。
>
> 自分で プログラムを 作るなら、TTA-8 ラボで 書いて「ボード用に保存」。
> 4_build に ドラッグして、2_write で 書きこむだけ！
>
> ブレッドボードが あれば、このボードの 外がわに 色々な 回路を 付けられる。
> おれたちの ぼうけん（電子工作）は、これからだ！
